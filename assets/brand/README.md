# Logo et identité Tchopi

Déposez ici les fichiers du logo (source unique pour l'app mobile et le site web) :

| Fichier | Contenu | Utilisé pour |
|---------|---------|--------------|
| `logo.svg` | Logo vectoriel (de préférence) | En-tête du site, écrans de l'app |
| `icon-1024.png` | Icône carrée 1024 × 1024 px, fond plein, sans texte fin | Icône de l'app (Android / iPhone), favicon |
| `logo-blanc.svg` (facultatif) | Version claire pour fonds sombres | Thème sombre, bandeaux sombres |

Ensuite, Claude génère les icônes de l'app, le favicon et l'image de partage du site.
