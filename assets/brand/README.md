# Logo et identité Tchopi

`logo.png` est le logo officiel (source, fond transparent). Tout le reste en est dérivé :

| Fichier dérivé | Usage |
|----------------|-------|
| `icon-1024.png` | Icône carrée (fond blanc) → icônes Android (`mipmap-*/ic_launcher.png`) et iPhone (`AppIcon`) |
| `packages/core/assets/images/logo.png` | Écran d'accès et animation de démarrage de l'app |
| `android/.../drawable/launch_logo.png` | Écran de lancement natif Android |
| site : `public/brand/logo.png`, `src/app/icon.png`, `apple-icon.png`, `favicon.ico`, `opengraph-image.png` | En-tête, pied de page, onglet, partage |

Pour un nouveau logo : remplacer `logo.png` et demander la régénération des fichiers dérivés.
